# HourSnap

School version of StormSnap: back camera + selfie, in the hours each person picks. Snaps vanish after 24 hours. Report button, admin tools.

- Android APK: built by GitHub Actions on every push to `main` (see Releases).
- Web app: Vercel (`npx expo export -p web` → `dist`).
- Backend: Appwrite Cloud (Frankfurt), project `hoursnap`.
